# Sound effects (local only)

The mix scripts load three files from here: `thud.wav`, `swoosh.mp3` and `click.mp3`. They come from Gabriel's SoundEffects folder and aren't committed because the repo is public.

Everything else (static bursts, LED blips, register beeps, flap clacks, needle swish, pen scratch, CRT power-down, tape hiss) is synthesized in code inside each reel's `mix.py`, so it needs no files.
